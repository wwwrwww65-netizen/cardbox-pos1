# 📱 تطبيق نقطة بيع كروت شبكات المايكروتك والإنترنت (POS System)

تطبيق أندرويد متكامل ومصمم بأسلوب حديث خصيصاً لأصحاب البقالات والمحلات التجارية ليكونوا **نقاط بيع معتمدة (POS)** لشبكات الإنترنت اللاسلكية وشبكات المايكروتك المحلية.

التطبيق مطور باستخدام أحدث تقنيات أندرويد (Kotlin + Jetpack Compose) ومتوافق 100% مع كافة سياسات ومتطلبات **Google Play Console (2025/2026)** بما فيها دعم Android 15/16 والتصميم حافة إلى حافة (Edge-to-Edge).

---

## 💡 طبيعة عمل التطبيق وماذا يجلب من السيرفر (System Architecture)

يتصل التطبيق بسيرفرات الخلفية (Backend API) وسيرفرات شبكات المايكروتك ليعمل كحلقة وصل رقمية آمنة وسريعة:

1. **جلب واستعراض شبكات الإنترنت (Networks):**
   - يجلب قائمة كاملة بشبكات الواي فاي والمايكروتك المتاحة (اسم الشبكة، الصورة، الموقع الجغرافي، حالة الاتصال والسيرفر، وإمكانية تثبيت الشبكات المفضلة).
2. **جلب باقات الشبكة وفئاتها (Packages & Profiles):**
   - عند اختيار شبكة معينة، يجلب التطبيق كافة الباقات المسجلة على السيرفر لتلك الشبكة (مثل: باقة 100 ريال، باقة 200 ريال، باقة أسبوعية، شهرية، إلخ).
   - يعرض تفاصيل الباقة: السعر، مدة صلاحية الكرت، حد التحميل/السرعة، والوصف.
3. **توليد وشراء الكروت فورياً (Voucher Generation & Purchase):**
   - عند قيام العميل بالشراء وتحديد الكمية ورقم الهاتف (اختياري)، يرسل التطبيق طلباً أمنياً للسيرفر.
   - يجلب السيرفر **رمز الكرت (Voucher Code)** الفريد والمولد آلياً من نظام المايكروتك.
4. **الطباعة الحرارية المباشرة (Thermal Printing Engine):**
   - يتصل التطبيق عبر البلوتوث (Bluetooth Thermal Printer) أو عبر الشبكة (LAN IP / TCP) بطابعات الإيصالات الحرارية (قياس 58mm / 80mm).
   - يطبع إيصالاً فورياً يحتوي على: اسم نقطة البيع، اسم الشبكة، اسم الباقة، **رمز الكرت** المولد، السعر، الترويسة والتذييل المخصصين، وتاريخ وساعة الشراء.
5. **إدارة المحفظة والرصيد (POS Wallet):**
   - يجلب رصيد نقطة البيع الحالي المتاح للشراء والسقف المالي.
   - يتيح شحن الرصيد عبر إيداع بنكي أو حوالة مع رفع صورة الإشعار للسيرفر.
6. **سجل المبيعات والتقارير (Sales History & Analytics):**
   - يحتفظ بسجل مفصل لجميع الكروت المباعة.
   - يتيح فلترة المبيعات (اليوم، الأسبوع، الشهر) وإعادة طباعة أي كرت سابق بنقرة واحدة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **لغة البرمجة والتطوير:** Kotlin 100%
* **واجهة المستخدم (UI Engine):** Jetpack Compose مع دعم كامل لنظام التصميم **Material Design 3 (M3)**
* **دعم اللغة والاتجاه:** تطبيق عربي حصري مع دعم تلقائي للاتجاه من اليمين لليسار (**RTL Layout Direction**)
* **قاعدة البيانات المحلية (Local Storage):** **Room Database** مع **KSP (Kotlin Symbol Processing)** لتخزين بيانات نقطة البيع، الشبكات المنضم إليها، السقف المالي، سجل المبيعات، وإعدادات الطابعة.
* **إدارة الحالة والنموذج (Architecture & State):** MVVM Architecture مع `ViewModel` و `StateFlow` و `collectAsStateWithLifecycle`
* **محرك الشبكات (API Layer):** Retrofit / Ktor Service Layer
* **محرك الطباعة الحرارية (Thermal Printing Engine):** محرك مخصص لإرسال أوامر **ESC/POS** المباشرة للطابعات الحرارية (طابعات البلوتوث 58mm / 80mm) مع وضع المحاكاة المباشرة واختبار طباعة الإيصالات.

## 🚀 التعديلات والمميزات المضافة والمحدثة مؤخراً

### 1. إعادة تطوير صفحة المبيعات (Sales History Screen):
* **التصميم العصري المطور (Material Design 3):** تحسين واجهة المبيعات ببطاقات إحصائية رئيسية تعكس إجمالي مبيعات الفترة، عدد الكروت المباعة، وعدد العمليات.
* **تصفية زمانية سريعة (Filter Chips):** إضافة شرائح تصفية تفاعلية (*جميع المبيعات*، *مبيعات اليوم*، *هذا الأسبوع*، *هذا الشهر*).
* **إزالة كلمة "PIN" بالكامل:** تم تنقيح وتغيير كافة النصوص والمسميات في جميع أجزاء التطبيق لتكون **"رمز الكرت"** بدلاً من PIN.
* **نسخ رمز الكرت بضغطة واحدة:** إضافة زر نسخ سريع يقدم إشعاراً فورياً بتأكيد نسخ رمز الكرت للحافظة.
* **إعادة الطباعة المباشرة:** إمكانية إعادة طباعة الفاتورة والكرت للطابعة الحرارية في أي وقت من سجل المبيعات.

### 2. شاشة معلومات حسابي ونقطة البيع (Account Details Screen):
* **هيكلة الشاشة:** استبدال خيار تغيير كلمة المرور المباشر بشاشة كاملة مخصصة تحت اسم **"معلومات حسابي ونقطة البيع"**.
* **بيانات المتجر والتأكيد:** تعرض وتتيح تعديل اسم المتجر/البقالة، الموقع التفصيلي، مع إبراز رقم الجوال الموثق وحالة الحساب.
* **الحماية عبر رمز الـ (OTP):** كافة العمليات الحساسة (تحديث بيانات المتجر، تغيير كلمة المرور، أو طلب حذف الحساب) مجهزة بنافذة تأكيد رمز أمان OTP.
* **منطقة حذف الحساب:** نقل زر حذف حساب نقطة البيع النهائي إلى أسفل شاشة تفاصيل الحساب لضمان عدم الضغط عليه بالخطأ.

### 3. الترويسة وتذييل الحقوق (Developer Footer):
* في أسفل شاشة "حسابي والإعدادات" وتحت زر تسجيل الخروج مباشرة، تم إضافة النص الرسمي لحقوق التطبيق والمطور:
  > **المطور جي كم للتسوق الإلكتروني**  
  > **جميع الحقوق محفوظة 2026**

### 4. إعدادات الطابعة الحرارية وتخصيص الطباعة:
* **خيارات الاتصال:** دعم الاقتران المباشر مع طابعات البلوتوث وتحديد عنوان IP للطابعات الشبكية.
* **التخصيص الكامل للإيصال:** إمكانية كتابة اسم المتجر في الترويسة، إضافة رقم الهاتف، وكتابة ملاحظة تذييل مخصصة تظهر في أسفل كل كرت مطبوع.
* **طباعة تجريبية:** توفير خيار طباعة إيصال تجريبي لاختبار محاذاة النص ووضوح رمز الكرت قبل البدء بالبيع.

### 5. الصفحة الرئيسية والبحث عن الشبكات (Home & Networks):
* **تثبيت الشبكات المفضلة (Pinning):** إمكانية تثبيت الشبكات الأكثر بيعاً ببطاقات بارزة في أعلى الصفحة الرئيسية للوصول السريع للباقات.
* **البحث المتقدم:** شاشة بحث فورية وسريعة عن الشبكات بالاسم أو المنطقة.

## 🛡️ التوافق التقني ومعايير قوقل بلاي (Google Play Policies 2025/2026)

- **مستوى الهدف (Target SDK Level):** التطبيق مستهدف ومضبوط على `targetSdk = 36` و `compileSdk = 36` (Android 16 / Android 15)، وهو متوافق تماماً مع شروط النشر والتحديث على قوقل بلاي كونسول.
- **دعم الشاشات حافة إلى حافة (Edge-to-Edge Design):** تفعيل `enableEdgeToEdge()` مع معالجة حواشي نظام الأندرويد (`WindowInsets.navigationBars` & `statusBars`) لضمان عدم تداخل الأزرار مع شريط الملاحة السفلية أو كاميرا الشاشة.
- **معمارية 16KB Memory Page Size:** مبني بنقاء عبر Kotlin & Jetpack Compose بدون مكتبات ناتيف غير متوافقة.
